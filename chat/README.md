# Yaari (가칭) — 글로벌 랜덤채팅 앱 (첫 시장: 인도)

로또 앱(`/android`)과 **완전히 분리된 독립 프로젝트**입니다. 이 폴더만 떼어 새 저장소로 옮겨도 그대로 빌드됩니다.

종료를 폰에 기록해 다음 실행 때, 그리고 가입·매칭·첫 메시지·방 만들기·입장·루도 시작·영상통화·Plus 구매 단계를 우리 서버(`log_events`)로 보냄(개인정보 없음, 20개씩 묶어서, 데모판은 보내지 않음). 0.7.0: 방이 한 종류로 통합(웹과 같음). 카테고리는 토크·음악·게임 셋, 모든 방에 채팅·음성 무대·같이 듣는 음악·루도·사진. 토크는 채팅 우선 + 아이스브레이커 카드, 음악은 플레이어 + 투표로 다음 곡, 게임은 루도 + 방 순위. 방 설정(인원 2–200, 성별, 나이, 비공개 코드, 공지), 코드로 입장, 사진은 보내기 전 폰에서 누드 검사(실서버판) 후 받는 쪽에서는 탭하기 전까지 가림. 음성(LiveKit)은 무대에 누가 있을 때만 연결. 예전 "채팅" 방 탭은 없어짐. 0.6.0: 보이스룸 안의 루도(호스트·공동호스트가 하단 게임 버튼으로 열기, 2–4명, 서버가 주사위와 규칙 판정, 15초 턴 제한, 관전). 0.5.0: 보이스룸(X Spaces식 음성 방, 채팅, 같이 듣는 YouTube 음악). 0.2.0–0.7.0과 같은 디버그 키라 덮어 설치됩니다(0.1.x는 지우고 설치).

APK·AAB 모두 디버그 키로 서명한 테스트용입니다. Play Store에는 `./gradlew bundleLiveRelease`로 만든 App Bundle(.aab)을 올립니다. 업로드 키는 `chat/upload.properties`(저장소에 올리지 않음)에 `storeFile`, `storePassword`, `keyAlias`, `keyPassword`를 적어 두면 자동으로 쓰입니다. Play가 폰 CPU에 맞는 파일만 내려주므로 실제 다운로드 크기는 더 작습니다.

## 검증

- **앱 테스트**: 총 373개(demo 181개 + live 192개, 실패 0, live 중 실서버 테스트 4개는 건너뜀). lint 오류 0. 실서버 통합 테스트 `LiveServerTest`는 테스트 봇과 QA 계정을 같이 쓰므로 봇을 끈 상태에서만 돌립니다. 계정 삭제 실서버 테스트 1개는 QA 계정을 지우므로 평소에는 건너뜁니다.
  - 규칙, ViewModel 22개, 전체 UI 흐름(화면 17장), 힌디어 화면, 받은 사진 가림.
  - ViewModel 테스트에는 서버 쪽 잠금 확인, 영상 수락, 메시지(DM), 매칭 중 이탈한 방 정리, 로그아웃 중 남은 방 정리, 결제 복원도 포함됩니다.
- **코드 리뷰 2회**: 1차 11건, 2차 4건 발견. 모두 수정했고, 2차 수정은 회귀 테스트가 실제로 버그를 잡는지 코드를 일부러 되돌려 확인했습니다.
- **실제 서버 통합 테스트** (`LiveServerTest`): 통과. 계정 삭제 기능도 실제 서버에서 QA 계정 하나로 확인했고, 삭제 후 해당 계정의 데이터가 남지 않은 것까지 확인했습니다.
  - 로그인 → 매칭 → 실시간 메시지 수신 → 서버의 5초 잠금 거부 → 구독 없는 영상 요청 거부 → 프로필 조회 → 상대가 나감 실시간 감지 → 최근 목록.
- **친구·공개방 SQL 테스트** (`server/test_social.sql`): 국기 위조 불가, 모르는 사람 요청 불가, 방에 없으면 글쓰기 불가, 발신자 이름 위조 불가, 도배 제한, 요청·수락·친구 메시지방, 신고 시 친구 해제·글 숨김. 모두 통과(실행 후 롤백).
- **서버 규칙 SQL 테스트**: 18세 미만 거부, 성별 변경 불가, 남의 채팅 읽기·쓰기 불가, 잠금, 구독, 차단, 자동 정지, 스팸 제한. 모두 통과.
- **서버 함수**: LiveKit 토큰 서명을 별도 JWT 라이브러리(jose)로 검증. 배포 후 미인증 요청 401, 키 미설정 503 확인.
- **Lint**: 오류 0개. R8 최적화 후에도 서버 데이터 변환 코드가 유지되는 것을 확인.
- **아직 못 한 것**: 실기기 테스트. 이 환경에는 에뮬레이터가 없습니다. 실제 영상통화는 LiveKit 키 설정 후 폰 2대로 확인해야 합니다.
