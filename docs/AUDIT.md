# 출시 전 종합 점검 (2026-10-19)

범위: 웹사이트, 안드로이드 앱, 결과 수집기(GitHub Actions), 법·정책, 광고, 경쟁 비교.
방법: 코드 직접 확인, 자동 테스트, 실제 브라우저 실행, 실제 사이트 링크 전수 확인, 공식 문서 확인. 추정은 "추정"이라고 표시.

확인했고 문제없던 것: 저장소·이력에 비밀키 없음, 사이트 XSS 방지(모든 값 이스케이프, innerHTML 미사용), 앱 외부 노출 컴포넌트 없음, 평문 통신 차단, QR 링크는 주소를 보여 주고 확인 후 열기.

## 2. 실시간 반영

- 미러 4곳(GitHub Pages, Cloudflare, jsDelivr, raw)이 같은 결과(같은 생성 시각)를 제공함을 확인.
- 1 PM: 게시 33초 후 푸시 발송 확인(이전 점검). 6 PM·8 PM은 오늘 저녁 실제 실행으로 확인 예정.
- 사이트: 오늘 페이지는 1분마다 새 결과를 확인해 자동 새로고침, Cloudflare 결과 파일 캐시 15초.
- 앱: 푸시 수신 → 15초 안에 새로 받기, 실패하면 백그라운드 작업이 재시도.

## 3. 광고 수익 (AdSense 승인 후)

- 자동 광고의 **사이드 레일**이 PC 화면 양옆 빈 공간에 붙음(구글 공식 형식, 데스크톱만). 우리 사이트는 가운데 폭이 좁아 적합.
- 휴대폰: 앵커(하단 고정) + 본문 광고(결과 아래, 등수 사이). 페이지당 수동 광고 최대 3개, 번호 안에는 넣지 않음.
- **도박·베팅 광고 카테고리는 차단 유지**(AdSense 기본값). Play 정책과 온라인게이밍법 §6 때문.
- 결과만 보여 주는 사이트는 AdSense "온라인 도박" 제한 대상 문구(티켓 구매 가능하게 하는 콘텐츠)에 해당하지 않음. 단 이것은 문서 해석이며, 승인 여부는 신청 결과로만 확정됨.

## 4. 경쟁 대비

우리만 있는 것: 공식 결과와 대조한 "검증" 표시, 다크 모드, 3개 언어 웹(앱 6개), 광고 방해 없음, 깔끔한 화면.

이번에 추가한 것: 추첨 생방송 버튼, 날짜로 지난 결과 찾기, 90일 번호 이력 검색(웹), 공유 미리보기 이미지(WhatsApp 등에 1등 번호가 보임), Telegram 채널 안내.

아직 없는 것 (우선순위순):
1. 결과지 이미지 페이지 (구글 이미지 검색 유입). 단, 남이 만든 결과지 이미지를 그대로 올리는 것은 저작권 위험 → 우리가 직접 그린 이미지로만.
2. 케랄라·서벵골·부탄 등 다른 복권 (검색량 큼, 대신 수집·검증 작업이 새로 필요).
3. 1 PM/6 PM/8 PM 요일별 게임 이름표(웹).

일부러 안 하는 것: 예측 번호, 행운 번호, 핫/콜드 번호 판매.

3. 도박·온라인 머니게임 광고 차단 (온라인게이밍법 §6, 2026-05-01 시행).
