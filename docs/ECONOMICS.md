# 수입·비용 모델 (2026-10-19 작성)

모든 수입 숫자는 **추정**입니다. 실제 광고 단가는 AdSense를 2~4주 돌려 봐야 나옵니다. 아래 표는 "이 정도 방문이면 이 정도"라는 계산 틀이고, 방문 수는 순위에 따라 수십 배씩 달라집니다.

## 1. 고정 비용 (월)

| 항목 | 비용 | 근거 |
|---|---|---|
| 웹 호스팅 (Cloudflare Pages/Workers 무료) | 0원 | 정적 파일 요청은 무료·무제한(Cloudflare 문서). 무료 배포 한도 월 500회, 우리는 결과가 바뀔 때만 배포해 월 300회 안팎 |
| 결과 수집 서버 (GitHub Actions) | 0원 | 공개 저장소는 무료 |

방문자가 늘어도 정적 사이트라 서버 비용은 늘지 않습니다. GitHub Pages는 상업용 사용이 약관상 제한되므로, 광고를 붙이는 시점에 Cloudflare로 옮깁니다(코드는 준비됨).

## 3. 수입: 웹 광고 (주 수입원)

**계산식:** 월 수입 = 월 페이지뷰 ÷ 1000 × 페이지 RPM(1000뷰당 수입)

**인도 RPM 근거:**
- upGrowth(2026-02): 뉴스·엔터테인먼트 분야 ₹40~165
- Ranktracker: 인도 일반 $1~3(약 ₹85~255)

복권 결과 방문자는 모바일·저가 요금제 비중이 높고 광고 단가가 낮은 편입니다. 우리는 광고를 페이지당 3개로 제한합니다. 그래서 **계획용으로 ₹30~100**을 씁니다. 환율은 ₹1 ≈ 16원으로 가정합니다.

| 단계 | 일 방문 | 월 페이지뷰 (방문당 2뷰) | 월 수입 (₹30~100) | 원화 |
|---|---|---|---|---|
| A. 새 도메인 첫 1~3개월 | 300~1,500 | 1.8만~9만 | ₹540~9,000 | 약 1만~14만 원 |
| B. 날짜별 긴 검색어 일부 상위 (6~12개월) | 5,000~20,000 | 30만~120만 | ₹9,000~1.2L | 약 14만~190만 원 |
| C. 주요 검색어 최상위 (가능성 낮음) | 10만 이상 | 600만 이상 | ₹1.8L~6L | 약 290만~960만 원 |

- AdSense는 누적 100달러가 되어야 지급하므로, A 단계에서는 몇 달 모아서 받습니다.
- 수입을 가장 크게 움직이는 것:
  1. 결과를 남보다 먼저 올리는 속도(이번에 고침)
  2. 날짜·시간이 붙은 검색어 순위
  3. 벵골어 페이지(서벵골 검색량)
  4. 하루 3번 다시 오는 사용자 비율
