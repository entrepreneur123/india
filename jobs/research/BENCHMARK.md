# 경쟁 서비스 기능 벤치마킹 (2026-10-20)

조사 대상
- sarkariresult.com: 홈과 SSC CHSL 2026 상세 페이지를 직접 받아 구조를 확인
- freejobalert.com: 홈과 도구 페이지를 직접 확인
- indianpaycalculator.in: Sarkari Result 도구 모음을 직접 확인
- Adda247, Naukri Alert, India Govt Job Finder, JagranJosh: 앱스토어 설명만 확인. 실제 앱을 써 본 것은 아닙니다.
